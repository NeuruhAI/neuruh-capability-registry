# Changelog

## 0.1.2a0 — v0.1.2-alpha

- New `neuruh-capability-registry` CLI: validate a manifest, and optionally one operation payload against it.
- Packaging metadata: PEP 639 `license`/`license-files`, project URLs, console-script entry point.
- README documents install, both the library and CLI paths with expected output, the public API, error codes, and the safety boundary.
- Continuous integration on Python 3.11, 3.12, and 3.13.
- Source formatting only in `core.py`; validation behavior is unchanged.

## 0.1.1a0 — v0.1.1-alpha

- Initial public extraction: typed capability manifest and fail-closed argument validator.
